# SEP Detector

HEVC / VVC 標準必要專利（SEP）必要性檢測工具，以 8 維度向量比對專利請求項與規格書章節。

## 頁面

網站首頁 `index.html` 是分頁外框，上方兩個分頁，網址可直接指定分頁：

| 分頁 | 網址 | 實際檔案 | 用途 |
|---|---|---|---|
| 必要性檢測工具 | `…/sep-detector/#tool` | `tool.html` | 單項檢測、批量模式、驗證資料庫 |
| 高通清單 | `…/sep-detector/#qcom` | `demo/ocean.html` | 魚群動畫：四大洋全景、權利人漩渦、土星錨點、撒網 vs 燈塔、經濟效益 |

- 分頁列右側「全螢幕」讓目前分頁全螢幕；「單獨開啟」不帶分頁列開啟該頁。
- 高通清單分頁第一次點開才載入；切走時動畫自動暫停。
- 工具頁首的「🐟 高通清單」與 Demo 的「← 回檢測工具」會切換分頁。

## 線上展示（GitHub Pages）

不需要登入，任何人開網址即可：

- 首頁（工具分頁）：`https://yuni94520.github.io/sep-detector/`
- 直接開高通清單：`https://yuni94520.github.io/sep-detector/#qcom`

設定：repo 的 **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選本頁所在分支、資料夾 `/ (root)`。

## 資料說明

- `data/`：HEVC 規格書章節、術語橋接規則、已驗證案例。
- 高通的 3,044 條魚各對應《合併去重主表》中的一筆真實家族，滑鼠移上可看公告號、標題、優先權日與被引次數；三星與其他權利人的魚為依統計分布生成的示意個體。
- 母數依期末報告（HEVC Advance 原始 43,095 → 分析母數 13,506；VVC Advance 3,076；高通 3,044 族）。
- 經濟效益數字來自《SEP 必要性檢測系統》簡報（人工每件 0.5 h、43,095 筆約 21,548 h vs 系統 72 h、API 帳單 $11,035／1.7 萬件、回測準確率 89.2%、精確率 88%、F1 85.5%）；人工單件驗證費用預設 US$10,000（Via Licensing 收費，見 TCL v. Ericsson, C.D. Cal. 2017 判決第 30 頁），可在頁面上調整。召回率由精確率與 F1 換算。
